PHASE 5 – PROJECT DEVELOPMENT PHASE

Project Title:
ComicCraft – AI Comic Story Creator

Frontend Development:

The frontend of ComicCraft was developed to provide a simple and user-friendly interface. Users can enter their story information and select the required options for generating a comic.

The application includes the following fields:

1. Story Prompt
2. Main Character
3. Setting
4. Story Tone
5. Art Style
6. Number of Panels
7. Generation Mode

Backend Development:

The backend receives the user input and processes the request through the application API. The backend is responsible for handling requests, processing data, communicating with the AI model, and returning the generated output.

AI Integration:

The AI model is integrated into the ComicCraft application to generate structured story content based on the user's input.

Technologies Used:

1. Python
2. FastAPI
3. HTML
4. CSS
5. JavaScript
6. Gemini API / AI Model
7. GitHub
8. Visual Studio Code

Project Output:

The system generates a structured comic story based on the user's prompt, character, setting, tone, art style, and selected number of panels.

Expected Outcome:

A functional ComicCraft application is developed with frontend, backend, API, and AI integration.
